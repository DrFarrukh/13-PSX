About This Dashboard

This is a static GitHub Pages dashboard for PSX (Pakistan Stock Exchange) financial analysis. It visualises pre-scraped financial data from Sarmaaya.pk.

🖥️ Full Interactive App (Streamlit)

The full app — with live data download, more charts, and interactive analysis — is built in Python/Streamlit. Run it locally:

git clone https://github.com/DrFarrukh/13-PSX.git
cd 13-PSX
pip install -r requirements.txt
streamlit run src/streamlit_app.py
📱 Android App (Flutter)

A Flutter/Dart Android app is also included in the flutter_app/ folder. See flutter_app/README.md for build instructions.
